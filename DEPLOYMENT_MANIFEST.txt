ISSUE FIXED:
  Dashboard envelope received with status=undefined (MISSING from JSON wire)
  Mutual exclusivity violation: both data AND error present in wire
  Result: "FT_STATUS_MISSING" error in UI console

ROOT CAUSE:
  Envelope factory functions used null values that still serialized to JSON
  JSON.stringify({data: null, error: {}}) produced both fields in wire

SOLUTION DEPLOYED:
  Use undefined for fields that should be omitted from JSON
  JSON.stringify({data: undefined, error: {}}) omits data field from wire
  Status field ALWAYS present in JSON (impossible to omit)
