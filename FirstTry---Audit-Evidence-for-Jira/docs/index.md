**Version**: 2.14.0  
**Platform**: Jira Cloud  
**Organization**: FirstTry Solutions

---

## Welcome

FirstTry Audit Evidence for Jira is a read-only dashboard gadget for Jira Cloud that provides governance snapshot summaries. This documentation portal provides comprehensive information for customers, reviewers, and security professionals.

**Key Features:**
- ✅ Read-only dashboard gadget for Jira dashboards
- ✅ Governance snapshot display and metadata storage
- ✅ Minimal scopes: `storage:app` and `read:jira-work` only
- ✅ No external network requests
- ✅ Automatic snapshot seeding on install and upgrade
