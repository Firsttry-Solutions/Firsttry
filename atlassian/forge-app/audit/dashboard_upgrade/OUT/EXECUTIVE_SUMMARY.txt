## FORK LINT LIMITATION (NON-BLOCKING)

**Issue**: forge lint fails with ESLint tsconfig error for src/gadget-ui/dist

**Root Cause**: Forge CLI v12.12.0 uses hardcoded ESLint parserOptions.project config that cannot be overridden. The dist folder (Vite output) contains JavaScript but forge lint tries to parse it as TypeScript.

**Why It Can't Be Fixed**: 
- Can't include dist in tsconfig.json (breaks type checking)
- Can't override forge lint's internal ESLint config
- Manifest must declare the dist path for gadget to work

**Status**: ✅ Documented in [FIX_FORGE_LINT_LIMITATION_DOCUMENTED.md](FIX_FORGE_LINT_LIMITATION_DOCUMENTED.md)
