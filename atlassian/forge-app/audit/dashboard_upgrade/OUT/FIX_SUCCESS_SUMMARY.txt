================================================================================

PATTERN: Vanilla DOM Renderers (no React)

  import { renderKpiTiles } from './enterprise/renderKpiTiles';
  
  function loadStatus() {
    try {
      const data = await invoke('get', {});
      
      // Call renderers (vanilla)
      renderKpiTiles({
        containerId: 'kpi-tiles-section',
        legacyData: data,
        unifiedStatus: data.unifiedStatus
      });
      
      renderStatusBanner({...});
      renderProgressTracker({...});
      applyExportPolicy({...});
    } catch(e) {
      // non-fatal
    }
  }

CONTAINER ELEMENTS (index.html):
  <div id="status-banner-section"></div>
  <div id="kpi-tiles-section"></div>
  <div id="progress-tracker-section"></div>

EXECUTION:
  1. loadStatus() invokes resolver (invoke 'get')
  2. Receives legacy payload + unifiedStatus field
  3. Calls 4 renderers (vanilla functions)
  4. Each renderer populates its container with DOM elements
  5. No React, no JSX, no dependencies
