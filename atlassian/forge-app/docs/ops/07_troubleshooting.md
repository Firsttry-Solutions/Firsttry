## Installation and Setup

### Symptom: "npm ci" fails with EACCES permission error

**Cause:** npm requires sudo, or directory ownership incorrect.

**Fix:**
```bash
# Option 1: Use nvm (no sudo required)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.5/install.sh | bash
source ~/.bashrc
nvm install 18
cd atlassian/forge-app
npm ci

# Option 2: Fix ownership
sudo chown -R $(whoami) ~/.npm
sudo chown -R $(whoami) $(pwd)/node_modules
npm ci
```

**Verification:** `npm ci` completes without errors.

---

### Symptom: "forge: command not found"

**Cause:** Forge CLI not installed or not in PATH.

**Fix:**
```bash
npm install -g @forge/cli
which forge  # Verify PATH
forge --version
```

**Verification:** `forge --version` shows >= 13.0.

---

### Symptom: Package-lock.json changes after "npm ci"

**Cause:** npm version mismatch, or lockfile generated by older npm.

**Fix:**
```bash
# Check npm version
npm --version  # Must be >= 9.0

# If < 9.0, upgrade
npm install -g npm@latest

# Regenerate lockfile
rm package-lock.json
npm install
git diff package-lock.json  # Review changes
```

**Verification:** `bash tools/prove_clean_install.sh` exits 0.

## Forge Authentication

### Symptom: "forge login" opens browser but fails

**Cause:** Localhost callback blocked, or browser session expired.

**Fix:**
```bash
# Try interactive mode
forge logout
forge login --interactive

# Or clear browser cache
# Delete cookies for *.atlassian.com in browser settings
```

**Verification:** `forge whoami` shows your email.

---

### Symptom: "Not authorized" when running forge commands

**Cause:** Auth token expired.

**Fix:**
```bash
forge logout
forge login
```

**Verification:** `forge whoami` succeeds.

**Cause:** TypeScript compilation error.

**Fix:**
```bash
# Working directory: atlassian/forge-app
npm run build  # See detailed errors
```

**Verification:** `forge deploy` completes successfully.

### Symptom: App not visible in Jira after installation

**Cause:** Installation incomplete, cache issue, or user permissions.

**Fix:**
1. Log out of Jira completely
2. Clear browser cache
3. Log back in
4. Navigate to Apps menu

**If still not visible:**
```bash
forge install --list  # Verify installation exists
forge install --upgrade  # Force refresh
```

**Verification:** App appears in Jira Apps dropdown.

**Cause:** User lacks required Jira permissions (not Forge issue).

**Fix:** Grant user appropriate Jira project permissions via Jira Admin settings.

**Verification:** User can access app UI without error.

## Audit

### Symptom: Audit exits 1 with "score < 85" but no blocking HIGHs

**Cause:** MEDIUM/LOW flags penalize score. If blocking_highs == 0 and score >= 70, this should be CONDITIONAL_ACCEPT.

**Fix:** Check scoring logic version. Commit 77f4d477d added 70-point threshold.
```bash
git log --oneline --grep="CONDITIONAL_ACCEPT threshold" | head -1
# Expected: 77f4d477d or later
```

**Verification:** Audit exits 0 with decision CONDITIONAL_ACCEPT.

---

### Symptom: Stability harness fails on run 2+ with different results

**Cause:** Non-deterministic behavior (should not happen).

**Fix:** This indicates a bug. Escalate to maintainers with:
```bash
# Preserve evidence
evdir=$(ls -td /tmp/ft_audit_stability_5x_* | head -1)
tar -czf /tmp/audit_failure_$(date +%s).tar.gz "$evdir"

# Report issue with archived evidence
```

**Verification:** None (requires maintainer fix).

---

### Symptom: Evidence directory missing results.json

**Cause:** Audit crashed before trap handler, or disk full.

**Fix:**
```bash
# Check disk space
df -h /tmp

# Check system logs for OOM
dmesg | grep -i 'out of memory'

# Retry after freeing space
```

**Verification:** Audit completes with results.json present.

---

### Symptom: "trufflehog unavailable" HIGH flag

**Cause:** trufflehog not installed (expected on many systems).

**Fix:** This is allowlisted (not a blocker). If you want to install:
```bash
brew install trufflesecurity/trufflehog/trufflehog  # macOS
# Or download binary for Linux from GitHub releases
```

**Verification:** Phase 02 no longer flags trufflehog unavailable.

---

### Symptom: Audit hangs for >5 minutes

**Cause:** Network timeout (external links), or npm operations slow.

**Fix:**
```bash
# Verify skip flags are set (should be automatic)
grep FT_SKIP_EXTERNAL_LINKS tools/audit/v3_1/run_f100_hostile_audit_v3_1.sh

# If hanging on npm, clear cache
npm cache clean --force
```

**Verification:** Audit completes in 2-3 minutes.

## CI

### Symptom: CI "Clean install proof" fails despite passing locally

**Cause:** CI uses strict environment (LC_ALL=C), local may differ.

**Fix:** Test locally with CI environment:
```bash
export LC_ALL=C LANG=C TZ=UTC
cd atlassian/forge-app
bash tools/prove_clean_install.sh
```

**Verification:** Exits 0 in CI environment.

---

### Symptom: CI passes but local audit fails

**Cause:** Local environment drift (wrong Node version, missing tools).

**Fix:**
```bash
# Verify Node version matches CI
node --version  # Must be 18.x

# Verify npm version
npm --version  # Must be >= 9.0

# Reinstall dependencies
cd atlassian/forge-app
rm -rf node_modules package-lock.json
npm install
git diff package-lock.json  # Should be minimal
```

**Verification:** Local audit matches CI result.

## Runtime

### Symptom: App loads blank screen in Jira

**Cause:** JavaScript error, missing assets, or backend timeout.

**Fix:**
1. Open browser developer console (F12)
2. Check for JavaScript errors
3. Check Network tab for failed requests

**Common causes:**
- Missing environment variables
- Backend function timeout
- CORS issue

**Check logs:**
```bash
forge logs --tail
```

**Verification:** App UI loads correctly, no console errors.

---

### Symptom: "Storage quota exceeded" error

**Cause:** Forge storage limit reached (default 5 MB per installation).

**Fix:** Implement data cleanup strategy, or request quota increase from Atlassian.

**Verification:** Storage operations succeed.

---

### Symptom: Backend function times out

**Cause:** Function exceeds 10-second execution limit.

**Fix:** Optimize function logic:
- Reduce API calls
- Implement pagination
- Cache results
- Use async/await properly

**Verification:** Function completes in <10 seconds.

## Data Issues

**Cause:** Storage key not properly scoped (CRITICAL security issue).

**Fix:** This should not happen (Forge provides automatic isolation). If observed:
1. DO NOT deploy to production
2. Escalate immediately to security.contact@firsttry.run
3. Provide reproduction steps

**Verification:** Cannot be verified locally (requires multiple installations).

## Diagnostic Commands

### Check System Health
```bash
# Disk space
df -h /tmp

# Memory
free -h

# Node/npm versions
node --version && npm --version

# Forge CLI status
forge whoami
```

### Check Repository State
```bash
# Working directory: repo root
git status
git log --oneline -5
git remote -v
```

### Check Dependencies
```bash
# Working directory: atlassian/forge-app
ls node_modules/ | wc -l
npm list --depth=0
npm outdated
```

### Check Audit State
```bash
# Find latest evidence
ls -td /tmp/ft_f100_hostile_audit_v3_1_* | head -1

# View decision
evdir=$(ls -td /tmp/ft_f100_hostile_audit_v3_1_* | head -1)
cat "$evdir/99_FINAL_DECISION.txt"

# Check for blocking HIGHs
jq '[.results[] | select(.severity=="HIGH" and (.allowlisted != true))] | length' "$evdir/results.json"
```
