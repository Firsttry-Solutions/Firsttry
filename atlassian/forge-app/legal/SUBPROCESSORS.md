# Subprocessors

**Last Updated**: 2026-01-10

## FirstTry Subprocessors

FirstTry does **NOT** use any third-party subprocessors for data processing.

### Data Handling

All governance data is:
- Stored in **Jira's Forge Storage** (Atlassian-managed)
- Encrypted at rest (Atlassian-managed encryption)
- Never sent to external APIs or third parties

### Infrastructure

FirstTry runs on:
- **Atlassian Forge Runtime** (serverless, managed by Atlassian)
- **Jira Cloud** (SaaS infrastructure managed by Atlassian)

### No External APIs

FirstTry does not integrate with:
- Analytics services (Mixpanel, Segment, etc.)
- Error tracking (Sentry, Datadog, etc.)
- Logging services
- CRM or marketing platforms
