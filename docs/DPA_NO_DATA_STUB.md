# Data Processing Addendum (DPA) — No Data Processed Stub

This app is designed so that:
- It does not process customer personal data as a data processor in the traditional sense.
- It does not store customer content or PII in external systems.
- Data access is limited to declared Forge scopes (see `docs/SCOPES.md`).

If future versions introduce storage or processing beyond this, this document must be replaced with a full DPA.
