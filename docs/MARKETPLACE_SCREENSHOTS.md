# Marketplace Screenshots — Required Set & Capture Rules

## Required screenshots (minimum)
1) Jira issue panel showing app output (no customer data).
2) Global/dashboard view (if applicable).
3) Empty/No-data state (shows safe behavior).
4) Permissions/config view (if applicable).

## Rules
- Do not capture real customer content.
- Blur site URL, issue keys, account IDs if visible.
- Use consistent window size.
- Use PNG.

## Naming
- marketplace_screenshots/01_issue_panel.png
- marketplace_screenshots/02_dashboard.png
- marketplace_screenshots/03_empty_state.png
- marketplace_screenshots/04_config_or_permissions.png

## Storage
- This repo includes the folder and naming convention.
- Do not commit real screenshots unless you explicitly decide to.
