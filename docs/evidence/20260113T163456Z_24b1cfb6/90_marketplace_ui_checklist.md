# Marketplace Submission UI Checklist (Manual)

## Required Verifications

- [ ] Privacy policy URL is set and matches repo docs

- [ ] Support contact email and Support Policy present
- [ ] Data handling description matches actual behavior
- [ ] Security summary matches evidence pack language

- [ ] Description matches functionality (no unproven claims)

## Scope Documentation

- [ ] Manifest scopes visible: `storage:app` (Forge app storage) + `read:jira-work` (read-only Jira)
- [ ] No write/delete/admin scopes claimed
- [ ] Data retention policy documented
