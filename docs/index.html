What This App Does

A read-only dashboard gadget for Jira Cloud that displays a governance snapshot summary. The snapshot contains audit evidence metadata derived from your Jira work data, stored entirely within Atlassian Forge Platform Storage. No data leaves Atlassian infrastructure.

  • Displays governance dashboard gadget in Jira Dashboards
  • Reads Jira work metadata (project info, issue counts, workflow states)
  • Stores governance snapshots in Forge platform storage
  • No write operations, no external network requests, no analytics
