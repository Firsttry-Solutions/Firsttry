## Short Description

## Full Description
FirstTry is a read-only Jira governance application designed for enterprise compliance and transparency.

### Proven Safety
- **Read-Only Scope**: Verified manifest - accesses only read:jira-user, read:jira-work, and app storage
- **No Network Egress**: Source code scanned - no external network calls
- **No Jira Mutations**: Source code scanned - database remains read-only
- **Transparent Architecture**: All proofs provided and independently verifiable

### Key Features
- Deterministic governance workflows
- Audit trail of all review decisions
- Non-invasive dashboard gadget integration
- Enterprise-grade scope restriction

### Use Cases
- Jira instance compliance monitoring
- Read-only governance app testing
- Transparent permission verification
- Enterprise security validation

### Technical Details
- **Architecture**: Forge app with guaranteed read-only scope
- **Data Access**: Jira users, work data (read-only), isolated app storage
- **Network**: No external API calls, no data exfiltration
- **Dashboard**: Optional gadget for governance status display
- **Performance**: Deterministic query patterns, no resource mutation
